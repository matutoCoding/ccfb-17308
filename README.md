# 圆顶-望远镜整夜推演系统

浏览器内运行的圆顶/赤道仪/观测计划整夜推演与碰撞复核系统。TypeScript + three.js,数据全部存 IndexedDB,无需后端。

## 运行

```bash
npm install
npm run dev        # 开发服务器
npm run build      # 产物到 dist/
npm run test:geom  # 几何精度验证 (坐标换算/运动学/圆顶方位解/遮挡/碰撞)
npx tsx test/sim.test.ts  # 整夜推演冒烟测试
```

首次打开自动生成测试数据: 冷湖赛什腾山站点 (38.6067°N, 93.8961°E, 4200m),2 个圆顶,6 台设备,1 个当晚计划,其中 **GEM-长筒(危险配置)** 是故意会撞的配置(长镜筒+长配重杆+矮墩+墩位贴边,整夜会产生接近/碰撞事件)。

## 五个页面

| 页面 | 功能 |
|---|---|
| 圆顶档案 | 直径/墙高/狭缝宽度/上下挡板行程/转速上限/加减速建档;一圆顶多墩位 |
| 望远镜装配 | 德式/叉式/地平式三种;墩子偏心、赤经轴→镜筒偏距、镜筒长径、遮光罩按实测填;三维预览里拖滑杆直接拧两根轴看姿态,实时显示光轴穿出点方位 |
| 观测计划 | 站点经纬度海拔、限制高度、地形遮挡剖面;CSV 导入目标(J2000),自动换算高度角/方位角,低于限高或进地形遮挡的时段标灰 |
| 整夜推演 | 30s 步长时间轴播放;圆顶伺服(转速/加速度上限)滞后真实可见;每步算入光口被狭缝边和挡板遮挡比例,画整夜曲线;可切镜筒视角看狭缝框住的天,被挡时段画面红框 |
| 碰撞复核 | 整夜所有接近(<5cm)/碰撞事件列表,点击跳到该时刻三维画面;可改翻转时机、加安全区厚度后重算 |

## 几何模型(关键约定)

- 坐标系: x=东, y=北, z=天顶;方位角自北向东。
- **圆顶方位不是望远镜方位**: 从入光口沿光轴作射线与穹顶球面求远交点(穿出点),圆顶方位 = 穿出点的水平方位。德式赤道仪翻转前后偏置方向相反,穿出点解自动跟随。验收场景(0.5m 偏心 GEM @ R=2.5m 圆顶)几何解自洽误差 ~0°(要求 <0.2°);同一批姿态下若直接拿望远镜方位角当圆顶方位,误差最大可达 ~178°。
- **遮挡**: 入光口圆盘 37 点向日葵采样,每个采样点沿光轴方向发平行射线,穿出点落在狭缝带(等宽竖直板条)且在当前上下挡板之间的记为通光,否则被挡。
- **赤道仪**: 极轴指向北天极,赤纬轴 = 绕极轴旋转的"东"向量;翻转 = 赤经轴转 180° + 赤纬角取反,光轴方向不变、镜筒落到本体另一侧。翻转过程按时间插值,期间 5s 子步加密碰撞采样。
- **碰撞**: 镜筒/遮光罩/配重杆/本体建模为胶囊体,墩子为实心圆柱,圆墙为薄壁圆柱,圆顶下沿为圆环;胶囊间用线段-线段解析距离,对环境 2cm 采样。接近阈值 5cm,穿入即碰撞。
- **圆顶伺服**: 1s 子步梯形速度规划(加速度限制 + 转速上限 + 最短路径),跟不上狭缝就滞后,滞后直接转化为遮挡。
- **同圆顶冲突**: 两台设备所需圆顶方位差超过狭缝半宽即记冲突事件,给出折中方位或错开时段建议。

## 数据

IndexedDB `dome-night-sim`: `domes` / `telescopes` / `plans` / `sims` 四个 store。夜报可导出 CSV 和 HTML(每目标: 有效曝光、被挡时长、翻转等待、转台、低于限高时长)。
